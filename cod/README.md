Carpeta cod

Esta carpeta contiene los archivos de código en R utilizados para desarrollar los ejercicios de la Tarea 3.

Archivos

01_datos.R: contiene el código relacionado con la preparación y procesamiento de los datos utilizados en el proyecto.

funciones_tarea3.R: contiene las funciones creadas para realizar los cálculos y análisis correspondientes a los ejercicios.

Uso

Los archivos se utilizan desde el documento principal de la tarea (Tarea3_SalasAndres.qmd).

Para cargar las funciones en R:

source("cod/funciones_tarea3.R")
