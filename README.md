Descripción

Este repositorio contiene el desarrollo de la Tarea 3, realizada mediante R, Quarto y Excel.

El trabajo está dividido en tres ejercicios:

Ejercicio 1: Análisis de alertas móviles.

Ejercicio 2: Aplicación de la ley de Benford por cantón.

Ejercicio 3: Cálculo del valor acumulado con interés.

Se incluyen los códigos utilizados, los datos, los resultados, las figuras y el archivo de Excel correspondiente.

Estructura del repositorio

Tarea3_SalasAndres.qmd: documento fuente del reporte.

cod/: funciones y archivos de código utilizados en los ejercicios.

data/: datos utilizados en el análisis.

config/: archivos de parámetros de configuración.

excel/: libro de Excel con los cálculos y verificaciones.

info/: figuras y gráficos generados durante el desarrollo.

Requisitos

Para reproducir el trabajo se necesita:

R.

RStudio.

Quarto.

Los paquetes de R utilizados en el documento y en las funciones.

Cómo reproducir el proyecto

Clonar o descargar este repositorio.

Abrir el proyecto en RStudio.

Verificar que los paquetes necesarios estén instalados.

Abrir el archivo Tarea3_SalasAndres.qmd.

Renderizar el documento utilizando el botón Render de Quarto.

Esto generará el reporte en formato HTML.
