Carpeta config

Esta carpeta contiene los archivos de configuración utilizados en la Tarea 3.

Archivos

parametros_tarea3.csv: contiene los parámetros definidos para los ejercicios, como tasas de interés y canales de análisis.

Uso

Los parámetros de este archivo son utilizados por el código en R para realizar los cálculos de acuerdo con los valores establecidos para cada ejercicio.

El archivo permite modificar los parámetros del análisis sin necesidad de cambiar directamente las funciones implementadas.
